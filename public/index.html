    This guide

    Reading the drawing

    Colour
    Where a node lies along the reference, as the key in the corner shows; charcoal nodes lie off it. View → Colour picks another scheme
    Width
    Read depth, while View → Width by depth is on
    Grey links
    Join node ends, their arrowheads pointing the way they read
    Dashed links
    Deletions: a link that skips reference sequence
    Halos and their labels
    Bubbles, labelled by kind, such as “≤241 bp ins”; click a label to open the bubble
    Gold outlines round a node
    The exons of the gene whose name stands above them

    Genes

    View → Reference says which assembly the graph's reference is on, and so which genes it shows, and takes JBrowse configs to find more. See genes and reference assemblies.

    BandageJS

    A pangenome and assembly graph viewer for the browser. It runs the force-directed layout of Bandage in wasm, and adds reference-anchored layouts, bubbles and haplotype walks. Released under the GPL-3.0-or-later license.
